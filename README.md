# 🍕 PerPiz — The Perfect Pizza

A modern, responsive restaurant website built for **PerPiz — The Perfect Pizza**, featuring an interactive digital menu, food categories, pricing, best sellers, shopping cart, WhatsApp ordering, QR-based menu access, and responsive design.

🔗 **Live Website:** [PerPiz — The Perfect Pizza](https://mohammedyaseen-777.github.io/PerPiz-Restaurant-Website/)

---

## 📌 About the Project

**PerPiz** is a frontend restaurant website created to provide customers with a modern and convenient way to explore the restaurant's menu and place orders.

The website presents pizzas along with other restaurant offerings such as tacos, burgers, French fries, pasta, garlic bread, dips, and desserts.

The project was designed with a focus on:

* Clean and modern UI
* Responsive design
* Easy menu navigation
* Interactive customer experience
* Digital menu accessibility
* Restaurant ordering workflow

## 🚀 Deployment

This project is deployed using **GitHub Pages**.

### Live Deployment

**[Visit PerPiz Website](https://mohammedyaseen-777.github.io/PerPiz-Restaurant-Website/)**

To deploy your own copy:

1. Fork or clone this repository.
2. Upload the project files to a GitHub repository.
3. Make sure `index.html` is located in the repository root.
4. Open **Settings → Pages**.
5. Select **Deploy from a branch**.
6. Select the `main` branch.
7. Select `/ (root)`.
8. Save the settings.
9. Wait for GitHub Pages to deploy the website.
